# JamCrate beta

Landing page and distribution for the JamCrate macOS beta.

- Install: `brew install --cask vitas/jamcrate/jamcrate`, or the newest release's `JamCrate.dmg` (universal binary — Apple silicon & Intel). Both are signed and notarized, so macOS opens them with a plain double-click.
- Install notes shipped inside the DMG: [DIST_README-notarized.md](DIST_README-notarized.md) for signed builds, [DIST_README.md](DIST_README.md) for the ad-hoc fallback.
- Web player (PWA): https://play.jamcrate.app
- Site: https://jamcrate.app

This repository only holds the public site source.

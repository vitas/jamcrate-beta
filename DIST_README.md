# JamCrate beta — install in 10 seconds
Drag JamCrate.app onto Applications. First launch: right-click the icon ▸ Open ▸ Open
(macOS asks once because the app is distributed outside the App Store).
If it still refuses: run in Terminal —
    xattr -dr com.apple.quarantine /Applications/JamCrate.app

Your library lives in ~/Music/JamCrate (move it any time: ⌘, ).
Everything stays on your machine. Feedback welcome — Help ▸ JamCrate Guide for the tour.

# JamCrate бета — установка на 10 секунд
Перетащите JamCrate.app в Applications. Первый запуск: правый клик по значку ▸ Открыть ▸ Открыть
(macOS спросит один раз — приложение распространяется не из App Store).
Если всё равно не пускает, в терминале:
    xattr -dr com.apple.quarantine /Applications/JamCrate.app
Библиотека — ~/Music/JamCrate (переносится в ⌘,). Всё остаётся на вашем Маке.
Обзор возможностей — в Help ▸ «Гид по JamCrate».

# JamCrate beta — install in 10 seconds
Drag JamCrate.app onto Applications.

The first launch asks once, because the app is distributed outside the App Store:
  · macOS 15 Sequoia or later — try to open JamCrate, then go to System Settings ▸
    Privacy & Security ▸ "Open Anyway".
  · macOS 14 Sonoma — right-click the icon ▸ Open ▸ Open.

If it still refuses, run this in Terminal:
    xattr -dr com.apple.quarantine /Applications/JamCrate.app

Your library lives in ~/Music/JamCrate (move it any time: ⌘, ).
Everything stays on your machine.

Questions, bugs and ideas: https://t.me/jamcrate (mostly Russian) or
https://github.com/vitas/jamcrate-beta/discussions (English).
Help ▸ JamCrate Guide for the tour.

# JamCrate бета — установка на 10 секунд
Перетащите JamCrate.app в Applications.

Первый запуск спросит один раз — приложение распространяется не из App Store:
  · macOS 15 Sequoia и новее — попробуйте открыть JamCrate, затем Системные
    настройки ▸ Конфиденциальность и безопасность ▸ «Всё равно открыть».
  · macOS 14 Sonoma — правый клик по значку ▸ Открыть ▸ Открыть.

Если всё равно не пускает, в терминале:
    xattr -dr com.apple.quarantine /Applications/JamCrate.app

Библиотека — ~/Music/JamCrate (переносится в ⌘,). Всё остаётся на вашем Маке.

Вопросы, баги и идеи: https://t.me/jamcrate или
https://github.com/vitas/jamcrate-beta/discussions.
Обзор возможностей — в Help ▸ «Гид по JamCrate».

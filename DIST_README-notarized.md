# JamCrate — install in 10 seconds
Drag JamCrate.app onto Applications. That is the whole install.

Signed and notarized by Apple, so it opens with a normal double-click — no
right-click, no System Settings detour, no Terminal.

Your library lives in ~/Music/JamCrate (move it any time: ⌘, ).
Everything stays on your machine: no account, no cloud, no subscription.

Questions, bugs and ideas: https://t.me/jamcrate (mostly Russian) or
https://github.com/vitas/jamcrate-beta/discussions (English).
Help ▸ JamCrate Guide for the tour.

# JamCrate — установка на 10 секунд
Перетащите JamCrate.app в Applications. Это вся установка.

Приложение подписано и нотаризовано Apple, поэтому открывается обычным двойным
кликом — без правого клика, без походов в Системные настройки, без терминала.

Библиотека — ~/Music/JamCrate (переносится в ⌘,).
Всё остаётся на вашем Маке: без аккаунта, без облака, без подписки.

Вопросы, баги и идеи: https://t.me/jamcrate или
https://github.com/vitas/jamcrate-beta/discussions.
Обзор возможностей — в Help ▸ «Гид по JamCrate».
